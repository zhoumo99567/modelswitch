# Model Switcher 连接工作台

本页设计替代旧 MASTER 中的 FAQ/OLED 模板。目标是桌面上的模型服务连接、技能整理与代理启动；保留树形导航、应用切换、调整宽度和设置入口。

## 视觉系统

- 深海蓝 `#123D4A`：固定侧栏与产品识别。
- 冷银 `#EAF0F1`：工作区底色。
- 瓷白 `#FAFCFC`：表单、列表和弹窗。
- 墨蓝 `#17323B`：正文与标题。
- 连接青 `#087D92`：主操作与选择。
- 信号金 `#E6B34A`：侧栏当前连接的小圆点。

字体使用本机 Avenir Next / Bahnschrift，中文 PingFang SC / Microsoft YaHei，避免网络字体依赖。标题 28、分区 18、表单正文 13、辅助信息 12px；等宽字体只用于实际路径、模型标识和配置代码。

## 布局比较

方案 A：并排独立卡片。操作被拆成相同圆角容器，与通用后台过于相似。

```
导航 | 标题                      应用
     | 当前连接卡片
     | [服务卡片] [模型卡片]
     | [路径卡片]
```

采用方案 B：连接工作台。左对齐，外边距 28–36px；表单按操作关系放在一块连续面板，左右留白一致。窄窗口堆叠分区，分隔线同时改为水平。技能采用一张连续列表，指标并排、操作靠右。

```
深海蓝导航 | 模型设置               当前应用
品牌连接图 | 说明
树形配置   | [服务 → 当前模型 → 应用] 恢复
技能       | 配置名称               应用配置
CLI        | ┌服务连接   │ 选择模型─────────┐
           | │表单       │ 模型/图像输入     │
           | └保存/获取──┴───────────────────┘
连接/设置  | 配置位置 / 文件操作
版本       |
```

## 设计审查与修订

去掉页标题上重复的面包屑标签；去掉每个区块统一的阴影和卡片包装。将星芒品牌图标改为连接线路图形，呼应模型服务与代理间的切换。技能不使用密集报纸栏或平铺同质卡片；只有整体列表外框和条目分隔线。视觉大胆之处集中在侧栏，主体保留克制的可读性。

按钮、表单、列表和弹窗分别使用 8/8/14/20px 圆角，不以装饰取代层级。弹窗内边距 28px，标题关闭按钮与分隔线保留 22px。深色模式使用深蓝灰工作区和浅青操作色。交互反馈不移动布局，减少动态偏好下不播放加载旋转。
